Behavior layer, memory store, or RAG?

They solve different problems. Memory and retrieval help an agent know more. A behavior layer decides which rules the agent must follow, and records why.

Memory stores and RAG vary a great deal by product. This table describes the typical pattern, not any one vendor. The one comparison we have measured is in the research: typed blocks with arbitration against retrieval over a user's past decisions.

Not either/or

Use them together.

Keep your RAG for knowledge

Retrieval is the right tool for answering from documents. The behavior layer does not replace it.

Keep your memory for continuity

Remembering what a user said last week is useful. It should not be what decides whether a refund is allowed.

Add the layer for rules and proof

When an agent must follow policy and a reviewer must be able to check it, the decision belongs in a layer that selects, arbitrates, and logs.
